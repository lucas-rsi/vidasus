VidaSUS

Plataforma digital de atendimento e agendamento em saúde pública.

Tecnologias

React
Python
Django
Django REST Framework
Google Gemini API

Como executar

Backend

cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver

Frontend

Em outro terminal:

cd react
npm install
npm run dev
